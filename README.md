# Numerical-calculation
Я написал код, который будет помогать вам следить за расходами за 5 дней.

# Принцип работы:
Принцип заключается в том, что мы вводим ежедневную трату и жмем enter, и так еще 4 раза (получается 5 дней).
Далее все ваши траты суммируются через цикл и выводятся на консоль.
В конце вы увидите самую большую трату за эти 5 дней.

# Как запустить?
1. Скачиваем файл.
2. Открываем Schetchik.csproj с помощью Visual Studio.
3. Нажимаем ctrl f5 и запуститься консольное окно.
4. Пользуемся!
